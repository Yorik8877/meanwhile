# Meanwhile

Карманные часы для параллельных задач.

Учёт времени по задачам, которые идут параллельно. Программа живёт в трее:
левый клик по иконке открывает окно, правый — меню с задачами.

- У каждой задачи свой таймер, несколько таймеров могут идти одновременно.
- Видно время за сегодня и за всё время, на вкладке «История» — по дням.
- Отрезки работы можно исправить, добавить и удалить.
- Сделанную задачу можно завершить: она уходит из списка и из трея на
  вкладку «Завершённые», остаётся в истории и в любой момент возвращается
  в работу.
- Сон компьютера, выключение и выход из программы ставят таймеры на паузу.
- После аварийного завершения теряется не больше минуты.
- Интерфейс на русском и английском. По умолчанию язык берётся из системной
  локали, сменить его можно шестерёнкой справа в строке вкладок.

## Требования

- Linux, X11 или Wayland (через XWayland).
- Для паузы во сне — D-Bus-интерфейс `login1`: его предоставляет
  systemd-logind или elogind. Без него программа работает, но во сне
  таймеры не останавливаются.
- Для сборки: Go, компилятор C и заголовки OpenGL и X11, которые нужны Fyne.
  Названия пакетов для разных дистрибутивов — в
  [документации Fyne](https://docs.fyne.io/started/). На Debian, Ubuntu
  и Mint:

  ```sh
  sudo apt install gcc libgl1-mesa-dev xorg-dev libxxf86vm-dev
  ```

Если libc целевой системы отличается от системы сборки (glibc и musl),
собирайте на целевой системе.

## Сборка и установка

```sh
make test        # тесты
make build       # bin/meanwhile
make install     # установка в домашнюю папку, sudo не нужен
```

`make install` кладёт бинарник в `~/.local/bin` и добавляет пункт в меню
приложений. Папку для бинарника можно сменить переменной `BIN_DIR`:

```sh
make install BIN_DIR=~/bin
```

Автозапуск при входе в систему включается в самой программе: шестерёнка
справа в строке вкладок, галочка «Запускать при входе в систему». У копии,
запущенной с `--data-dir`, этой галочки нет, чтобы она не подменила
автозапуск установленной программы.

## Удаление

```sh
make uninstall           # удаляет программу, данные остаются
make uninstall PURGE=1   # спрашивает и удаляет ещё базу и логи
```

Перед удалением выйдите из программы через меню трея — иначе `make uninstall`
остановится с подсказкой.

## Где лежат файлы

| Что | Путь |
| --- | --- |
| База SQLite | `~/.local/share/meanwhile/meanwhile.db` (или `$XDG_DATA_HOME/meanwhile/`) |
| Лог | `~/.local/state/meanwhile/meanwhile.log` (или `$XDG_STATE_HOME/meanwhile/`) |
| Замок и сокет единственного экземпляра | `$XDG_RUNTIME_DIR/meanwhile.{lock,sock}` |

## Флаги

- `--hidden` — запуститься в трее, не показывая окно (так запускает автозапуск).
- `--data-dir <папка>` — хранить базу, лог, замок и сокет в указанной папке.
  Удобно для разработки: отладочная копия не трогает рабочие данные
  и не мешает установленной.

Повторный запуск программы не создаёт вторую копию, а показывает окно
уже работающей.

## Устройство

Дизайн описан в [docs/superpowers/specs/2026-10-14-meanwhile-design.md](docs/superpowers/specs/2026-10-14-meanwhile-design.md).

```text
cmd/meanwhile/       точка входа: флаги, пути, лог, связывание компонентов
internal/tracking/   задачи, отрезки, подсчёт времени (без Fyne и SQLite)
internal/storage/    хранение в SQLite
internal/power/      пауза при сне и выключении через login1
internal/instance/   единственный экземпляр: flock и Unix-сокет
internal/ui/         окно, история, редактор отрезков, трей, переводы
```
